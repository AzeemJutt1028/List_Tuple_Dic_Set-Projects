# Python Lists, Dictionaries, Tuples & Sets Projects

A collection of Python projects exploring core built-in data structures — lists, dictionaries, tuples, and sets — covering data storage, retrieval, sorting, and manipulation, built purely for **practice purposes**.

> ⚠️ **Note:** These are simple, beginner-level scripts written for learning and hands-on practice. They are not optimized, production-ready, or feature-complete applications — just stepping stones for building a strong foundation in Python.

## Projects

| # | Project | Description |
|---|---------|-------------|
| 1 | **To-Do List** | In-memory task manager to view, add, remove, mark tasks as completed, and clear all — using a list |
| 2 | **Contact Book** | Menu-driven contact manager to add, view, search, update, delete, and count contacts — using a dictionary |
| 3 | **Student Database** | Manages student records (name, age, department, CGPA) with nested dictionaries, including a "show top student" feature |
| 4 | **Shopping Cart Calculator** | Adds items with price/quantity to a cart (list of dictionaries) and calculates item and grand totals |
| 5 | **Duplicate Remover** | Removes duplicate values from a list of numbers while preserving order |
| 6 | **List Sorting** | Sorts a list of numbers in ascending or descending order using a manual bubble-sort-style algorithm (no built-in `sort()`) |
| 7 | **Frequency Counter** | Counts character or word frequency in a given text using a dictionary |
| 8 | **Common Elements Finder** | Finds elements shared between two lists |
| 9 | **Matrix Operations** | Performs matrix addition (3x3) and matrix transpose (2x3) using nested lists |
| 10 | **Inventory Management System** | Menu-driven system to add, view, search, update, delete products, and calculate inventory value — using a list of dictionaries |

## Concepts Covered

- Lists, dictionaries, nested dictionaries, and nested lists
- CRUD-style operations (add, view, search, update, delete) on in-memory data
- Manual sorting algorithms without built-in `sort()`
- Dictionary-based counting and frequency tracking
- Menu-driven program flow with input validation
- Basic matrix representation and manipulation

*(File handling, exception handling, and OOP are intentionally excluded — these will be covered in separate, more advanced projects.)*

## How to Run

Each project is a single, self-contained `.py` file. Run any of them with:

```bash
python "project_name.py"
```

## Purpose

This repository is part of my Python learning journey — built to practice data structure fundamentals through small, hands-on projects rather than to serve as polished, real-world software. Expect simple console-based interfaces and straightforward logic throughout.
